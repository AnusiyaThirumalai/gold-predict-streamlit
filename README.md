 💰 Gold Price Prediction (India) – ML + Flask + Streamlit

This project predicts **weekly Gold Prices in India** using machine learning models trained on USD/INR and past gold prices.  
It includes:

✅ Exploratory Data Analysis (EDA)  
✅ Machine Learning model training  
✅ Flask REST API  
✅ Streamlit UI Dashboard  
✅ Future Forecasting  
✅ Real-time USD/INR Fetching
